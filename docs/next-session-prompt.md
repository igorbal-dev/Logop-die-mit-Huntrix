# Speech Academy — продолжение (промпт для новой сессии)

Продолжаем проект Speech Academy — логопедические занятия для моей дочки Эмили (5 лет, Берлин, дома русский, немецкий слабый, диагноза нет).

Репозиторий: igorbal-dev/Logop-die-mit-Huntrix, рабочая ветка `claude/speech-academy`. Сначала `git fetch` и `git pull` её и `main` (я мог положить туда картинки). Сайт: https://igorbal-dev.github.io/Logop-die-mit-Huntrix/

Сначала прочитай `CLAUDE.md` в корне — там всё устройство, правила и решения. Ещё: `docs/plan-speech-academy.md` (план и логопедия, разделы 4.2а и 5), `docs/kak-polzovatsya.md` (инструкция для меня), `docs/voice-check.md` (что в озвучке сомнительно), `sprites-speech-academy.md` и `docs/prompt-rumi-komplett.txt` (картинки и промпты для ChatGPT).

## Что уже есть (кратко)
- Уроки 1–5 по 5 станций (разминка → слушаем → звуки → танец → слова → игра), прогресс, яйцо-награда, ⚡ быстрый режим.
- Дыхание: 10 игр + «футбол языком»; гимнастика языка у зеркала (блинчик, иголочка, чашечка, горка, грибок, качели, маляр, часики, варенье…) со схемами и анимацией; «лошадка» — щелчки языком через микрофон.
- 13 игр-закреплений, разнообразие на втором круге, 4 песенки и «Stopptanz».
- Программа по трудным звукам (Sch, S, Z, K/G, L, R, Ch, F/W, T/D): я отмечаю звуки в родительском разделе, уроки строятся под них, этапы слушаем → отдельно → слоги → начало → середина/конец → фраза, паспорт звука, «послушать и отметить» записи Эмили потом.
- Rumi перерисована (8.11, фиолетовые волосы, жёлтая куртка), `aligned: true` в `config/teachers.json` — все кадры по образцу.
- Озвучка — edge-tts через `tools/tts.py` с проверкой Whisper/DNSMOS (venv из `tools/requirements-voice.txt`, прокси-сертификат `/root/.ccr/ca-bundle.crt`). Chatterbox и ElevenLabs не использовать.
- Публикация — только `sh tools/publish.sh "что нового"`.

## Что ждёт от меня
- Полный архив Rumi 1024 px (сейчас стоит лёгкая версия 512 px) — пришлю, когда буду дома. Положить вместо текущих (WebP, качество 88).
- Проверка на телефоне: задувание и щёлканье «лошадки», надутые щёки, программа по звукам, озвучка.

4. Постановка звука от позы языка (например, «чашечка + подуть тёплым воздухом = Sch»), «как Эмили говорит» в паспорте звука.
