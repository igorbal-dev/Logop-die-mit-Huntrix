# Speech Academy

Короткие ежедневные логопедические занятия для Эмили: три учительницы, «зеркало» с камерой, микрофон, награда-яйцо.

- Сайт: https://igorbal-dev.github.io/Logop-die-mit-Huntrix/
- План и логопедическая программа: [docs/plan-speech-academy.md](docs/plan-speech-academy.md)
- Картинки учительниц (что рисовать, промпты для ChatGPT, куда класть): [sprites-speech-academy.md](sprites-speech-academy.md)
- Картинки кладутся в `assets/teachers/teacher1/`, `teacher2/`, `teacher3/` — подхватываются сами.
- Имена учительниц: `config/teachers.json`.

Камера и микрофон работают только на устройстве; видео и звук никуда не отправляются.
