# Speech Academy — правила для Claude Code

Логопедические занятия для Эмили (5 лет, Берлин, дома русский, немецкий слабый, диагноза нет). Отдельное приложение рядом с игрой Emily-game (репозиторий igorbal-dev/Emily-game, ветка `claude/emily-game-port`) — оттуда перенесены микрофон, звук, лестница подсказок, стиль. Игорь не программист и не логопед: логопедические решения принимает Claude, отвечать просто и коротко, по-русски.

## Ветки и публикация
- Работа — ветка `claude/speech-academy`. `main` — то, что опубликовано (GitHub Pages из `main`, корень): `https://igorbal-dev.github.io/Logop-die-mit-Huntrix/`.
- Публикация — ТОЛЬКО `sh tools/publish.sh "что нового"`: ставит новую версию в адреса файлов (`?v=…` в index.html, `SA_V`, `version.json`), коммитит, сливает в `main`, пушит. Без новой версии телефон показывает старую копию из памяти (так было 5.11). Приложение при старте сверяет `version.json` и само перезагружается, если открыта старая копия. Все загрузки файлов — через `SA.ver(url)`.
- Озвучка делается прямо в сессии (`tools/tts.py`), ветка `claude/voice` (старый Chatterbox) больше не нужна.
- Игорь может сам класть картинки в `assets/teachers/teacherN/` (через сайт GitHub в `main` или в рабочую ветку) — перед работой `git pull` обеих веток.

## Устройство (статический HTML/JS, без сборщика)
- `index.html`, `css/app.css`, `js/`: `util.js` (SA, sleep/«закончить раньше»), `audio.js` (реплики, очередь, голос браузера как временная замена, звуки, музыка танца), `breath.js` (распознавание выдоха), `mic.js` (детектор голоса из игры + «сырой» микрофон для выдоха + запись «послушай себя»), `teachers.js` (картинки, выравнивание, заглушки кодом, рот по громкости), `camera.js` (MediaPipe в браузере, `vendor/mediapipe/`), `pics.js` (картинки слов кодом), `tasks.js` (кирпичики заданий), `games.js` (игры-закрепления), `lessons.js` (уроки 1–5 по 5 упражнений), `session.js` (карта урока, запуск упражнения), `progress.js` (localStorage `speech-academy`), `parent.js` (родительский раздел), `main.js`.
- Учительницы: `config/teachers.json` — имена, цвета заглушек, папки. Учительницы: 1 = **Rumi** (25 картинок), 2 = **Mira** (14), 3 = **Zoey** (21, произносится «Зои»; в озвучке пишем «Sohi») — все картинки получены 4.11.
- Картинки от Игоря (PNG ~1,4 МБ каждая) Claude переводит в WebP (качество 88, тот же размер и имя, только `.webp`) — в 10 раз легче для телефона; PNG в репозиторий не класть. Загрузчик ищет .png → .webp → .jpg. Список картинок — `sprites-speech-academy.md` и `T.NEED` в `js/teachers.js` (держать одинаковыми).
- Реплики: `content/de/lines.json` (ключ → учительница, язык, текст). Записи: `assets/snd/<ключ>.mp3`. Нет записи — говорит голос браузера. Русская программа позже: `content/ru/…`.
- План и логопедия: `docs/plan-speech-academy.md`.

## Правила занятия
- Сначала немецкий, потом другая немецкая формулировка, третья подсказка — русская. Одна фраза подряд не звучит (`A.sayOne`).
- Максимум 3 попытки, потом похвала за старание и дальше. Никаких «неправильно», штрафов, потери прогресса.
- Микрофон засчитывает попытку (любой голос), произношение автоматически не оцениваем; правильность — кнопки родителя ✓ / ~. Слушание — по нажатиям (объективно).
- Камера: автоматически засчитываем только улыбку, трубочку, открытый рот, щёки. Язык — таймер или ✓ родителя. Никаких процентов.
- Гимнастика рта — разминка, основное время — слушание и произнесение. Незнание немецкого слова — не ошибка (сначала учительница называет картинку).
- Яйцо: за законченное занятие (или законченное раньше, если прошло ≥ половины). Название награды в озвучке не звучит.

## Озвучка — нейронные голоса Microsoft (edge-tts) + автопроверка (с 5.11; Chatterbox и ElevenLabs НЕ использовать)
- Почему сменили: Chatterbox давал реальные ошибки (распознавание: «Puppe» → «Topf», «Pusteblume» → «Pustebiome», лишнее бормотание). Сравнение — DNSMOS и Whisper: Katja лучше всех.
- Голоса — `config/voices.json`: Zoey (3) = Katja (образцы для повторения, без изменений), Mira (2) = Katja ниже/медленнее (ей тоже нужна точность — слоги-загадки), Rumi (1) = Amala (только инструкции). Русский — Svetlana (родной); если Svetlana не отвечает — тем же немецким голосом учительницы. Seraphina НЕ брать: «англизирует» немецкие слова (Tasche → Tash).
- Генерация и проверка: `python3 tools/tts.py` (новые), `--all` (всё, продолжает с места остановки), `--keys a,b`, `--check`. Каждая запись проходит Whisper large-v3-turbo (текст сравнивается с оригиналом, до 3 попыток с другим темпом) и DNSMOS. Отчёт — `tools/voice_report.json` и `docs/voice-check.md` (что послушать человеку). Окружение: venv с `tools/requirements-voice.txt`; в облачной сессии прокси-сертификат подхватывается сам.
- В реплике можно задать `say` (как произносить) и `expect` (что должно распознаться).
- Короткие слоги распознаватель слышит плохо — для них ему подсказывается ожидаемый текст; сомнительные всё равно в отчёте.
- Старые файлы Chatterbox (`tools/chatterbox/`, `.github/workflows/voice.yml`, ветка `claude/voice`) больше не нужны для озвучки.

## Дыхание (js/breath.js, игры в js/tasks.js)
- Выдох = громкий шум без тона (периодичность < 0,5), не чистое «ссс» (< 75 % энергии выше 3,5 кГц), не сразу после голоса (≥ 0,2 с), ≥ 120 мс. Фон — 15-й перцентиль громкости за 4 с (подстраивается всегда). 6.11 ослаблено: Игорь (взрослый) не мог задуть — фильтр шипения 45 % отсекал настоящий выдох в микрофон, фон застревал.
- Микрофон для дыхания — БЕЗ шумоподавления; основной на это время закрывается (`M.breathOpen/Close`).
- Подстраховка камерой: в дыхательных играх в углу окошко камеры; если видна поза «губы трубочкой» (`C.sees('blow')`), игра идёт на 60 % скорости, «пф» губами гасит свечку. Камера одна на всю разминку (`X.camInto`), выключается после зеркала.
- 10 игр на одном движке `breathGame`: Pusteblume, Kerzen, Ballon, Zauberflöte (мелодия «Alle meine Entchen»), Suppe (остудить), Seifenblasen, Windrad, Blätter (сюрприз под листьями), Wolke (солнце), Bootrennen (гонка с Rumi, Эмили всегда успевает). В каждом уроке 2 разные; на втором круге — случайные, не как в прошлом уроке (`X.pickBreath`). Игра не проигрывается.
- Проверка: `node tools/test/breath_test.js`. Родитель: «проверить дыхание» показывает цифры (тон, верх, низ, над фоном) — если у Игоря не ловится, попросить скриншот и подстроить пороги.

## Программа по звукам (с 5.11, план раздел 5)
- `js/sounds.js` — 9 звуков (слова начало/конец, слоги, фразы, гимнастика, совет родителю, этапы); `SA.soundLesson(код)` в lessons.js; `SA.curLesson()` — какой урок сейчас (session.js, parent.js). Картинки новых слов — `js/pics2.js` (`SA.addPics`).
- Прогресс: `d.snd = {list, st: {код: {stage, log}}, next}`, `prog.kind/snd/k`; `P._plan` (2 урока звука, 1 общий), `P.sndEval` (этап дальше: 2 урока подряд ≥ 80 % ✓ из ≥ 4; «слушаем» — по нажатиям), `P.markAt` (отметка потом). Попытки помечаются `{snd, stage}` (только те, что считаются для этапа).
- Записи попыток — IndexedDB `sa-rec` (`SA.Rec`, последние 120), в родительском разделе «Послушать и отметить». Настройка `keepRec`.

## Камера
- Улыбка, трубочка, рот — как было (blendshapes), не трогать. Щёки: `cheekPuff` у MediaPipe мёртвый (0 даже на рисованных надутых щеках). Своё правило: ширина нижней части лица (точки 58–288, 172–397, 136–365, 150–379 / расстояние между глазами) больше «спокойной» ширины этого же ребёнка на 3 % и рот закрыт. Спокойная — 40-й перцентиль спокойных кадров за время зеркала. Проверка на картинках: `tools/test/face_test.html`. Родитель: «проверить камеру» показывает % ширины щёк.

## Проверка
- ⚡ Быстрый режим (родительский раздел, `settings.quick`, `SA.quick()`): каждое задание один раз (из длинного списка — равномерно 1–2), зеркало 1 повтор, танец 5 с, станции в любом порядке, значок ⚡ на карте. Урок ≈ 3 мин. Для Игоря, чтобы проверять без повторов.
- `python3 -m http.server 8765` и в браузере `index.html?auto=1&speed=4` — автопрохождение (ответы засчитываются сами). Без параметров — обычный режим.
- Телефон 844×390, iPad 1180×820 и вертикально — Игорь проверяет сам. Максимум одна короткая автопроверка.

## Структура (с 5.11)
- Урок = 5 упражнений-станций на карте (`js/session.js`, `js/lessons.js`): 1 разминка (дыхание + зеркало, Rumi) → 2 слушаем (Mira) → 3 звуки/слоги (Zoey) → танец → 4 слова (Zoey) → 5 игра (Zoey). Каждое ≈ минуты_урока/5 (по умолчанию 3 мин). Сделанная станция сохраняется сразу; продолжить можно с той же; вперёд не перескакивать. 5 станций → яйцо, следующий урок; после урока 5 — круг заново со «сложнее» (level +1).
- Уроки 1–5: гласные и звукоподражания · губы M/B/P · кончик языка T/D/N/L · задний язык K/G · S/Sch на слух. Урок 5 «слова» — повтор слов, отмеченных родителем «~ трудно».
- Темп: объяснение один раз за упражнение (`X.once`), ответ можно сразу — нажатие обрывает реплику (`A.cut`), подсказки только после 7 с бездействия, кнопка «?» повторяет объяснение, похвала голосом через раз.
