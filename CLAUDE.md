# Speech Academy — правила для Claude Code

Логопедические занятия для Эмили (5 лет, Берлин, дома русский, немецкий слабый, диагноза нет). Отдельное приложение рядом с игрой Emily-game (репозиторий igorbal-dev/Emily-game, ветка `claude/emily-game-port`) — оттуда перенесены микрофон, звук, лестница подсказок, стиль. Игорь не программист и не логопед: логопедические решения принимает Claude, отвечать просто и коротко, по-русски.

## Ветки и публикация
- Работа — ветка `claude/speech-academy`. `main` — то, что опубликовано (GitHub Pages из `main`, корень). Публикация = слить рабочую ветку в `main` и запушить (сайт обновится через 1–2 мин): `https://igorbal-dev.github.io/Logop-die-mit-Huntrix/`.
- Озвучка — ветка `claude/voice` (только для GitHub Actions, большие wav туда, не в main).
- Игорь может сам класть картинки в `assets/teachers/teacherN/` (через сайт GitHub в `main` или в рабочую ветку) — перед работой `git pull` обеих веток.

## Устройство (статический HTML/JS, без сборщика)
- `index.html`, `css/app.css`, `js/`: `util.js` (SA, sleep/«закончить раньше»), `audio.js` (реплики, очередь, голос браузера как временная замена, звуки, музыка танца), `mic.js` (детектор голоса из игры + выдох + запись «послушай себя»), `teachers.js` (картинки, выравнивание, заглушки кодом, рот по громкости), `camera.js` (MediaPipe в браузере, `vendor/mediapipe/`), `pics.js` (картинки слов кодом), `tasks.js` (задания), `session.js` (план занятия и часы), `progress.js` (localStorage `speech-academy`), `parent.js` (родительский раздел), `main.js`.
- Учительницы: `config/teachers.json` — имена, цвета заглушек, папки. Учительницы: 1 = **Rumi** (25 картинок), 2 = **Mira** (14), 3 = **Zoey** (21, произносится «Зои»; в озвучке пишем «Sohi») — все картинки получены 4.11.
- Картинки от Игоря (PNG ~1,4 МБ каждая) Claude переводит в WebP (качество 88, тот же размер и имя, только `.webp`) — в 10 раз легче для телефона; PNG в репозиторий не класть. Загрузчик ищет .png → .webp → .jpg. Список картинок — `sprites-speech-academy.md` и `T.NEED` в `js/teachers.js` (держать одинаковыми).
- Реплики: `content/de/lines.json` (ключ → учительница, язык, текст). Записи: `assets/snd/<ключ>.mp3`. Нет записи — говорит голос браузера. Русская программа позже: `content/ru/…`.
- План и логопедия: `docs/plan-speech-academy.md`.

## Правила занятия
- Сначала немецкий, потом другая немецкая формулировка, третья подсказка — русская. Одна фраза подряд не звучит (`A.sayOne`).
- Максимум 3 попытки, потом похвала за старание и дальше. Никаких «неправильно», штрафов, потери прогресса.
- Микрофон засчитывает попытку (любой голос), произношение автоматически не оцениваем; правильность — кнопки родителя ✓ / ~. Слушание — по нажатиям (объективно).
- Камера: автоматически засчитываем только улыбку, трубочку, открытый рот, щёки. Язык — таймер или ✓ родителя. Никаких процентов.
- Гимнастика рта — разминка, основное время — слушание и произнесение. Незнание немецкого слова — не ошибка (сначала учительница называет картинку).
- Яйцо: за законченное занятие (или законченное раньше, если прошло ≥ половины). Название награды в озвучке не звучит.

## Озвучка — только Chatterbox (ElevenLabs НЕ использовать)
1. Новые реплики — в `content/de/lines.json`. `python3 tools/voice_queue.py` → `tools/chatterbox/probes.json` (только те, у которых нет mp3).
2. Commit, затем `git push origin claude/speech-academy:claude/voice` (или merge в `claude/voice`) → workflow `voice.yml` (8 параллельных заданий, ~15 мин). Если сам не запустился — GitHub MCP `actions_run_trigger` run_workflow `voice.yml` ref `claude/voice`.
3. `git fetch origin claude/voice`, достать `samples/chatterbox/*.wav` (например `git archive`/`git checkout origin/claude/voice -- samples` во временную папку) → `python3 tools/voice_import.py <папка>` → `assets/snd/<ключ>.mp3`.
- Голоса (образцы `tools/chatterbox/voices/`): t1 — ведущая игры (Skittle Bee) +2 полутона, бодрая; t2 — Хайке (Rhea), спокойная; t3 — ведущая игры как есть, самая чёткая (образцы для повторения). `_ru` — то же для русских подсказок (narr_ru). Настройки exaggeration 0.6, cfg 0.5, temperature 0.8.

## Проверка
- `python3 -m http.server 8765` и в браузере `index.html?auto=1&speed=4` — автопрохождение (ответы засчитываются сами). Без параметров — обычный режим.
- Телефон 844×390, iPad 1180×820 и вертикально — Игорь проверяет сам. Максимум одна короткая автопроверка.
